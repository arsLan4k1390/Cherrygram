# Third-party icon assets

The icon packs added in `res-material`, `res-fluent` and `res-vkui` are
converted from open-source icon sets distributed via Iconify
(https://iconify.design).

## Material Symbols

- Source: https://github.com/google/material-design-icons
- Author: Google
- License: Apache License 2.0 — https://www.apache.org/licenses/LICENSE-2.0
- Iconify prefix: `material-symbols`

## Fluent UI System Icons

- Source: https://github.com/microsoft/fluentui-system-icons
- Author: Microsoft
- License: MIT — https://opensource.org/licenses/MIT
- Iconify prefix: `fluent`

## VKUI Icons

- Source: https://github.com/VKCOM/icons
- Author: VK
- License: MIT — https://opensource.org/licenses/MIT
- 24px SVG icon set

The vector drawables are mechanical conversions of the original SVGs
(fill colour replaced with `#FFF` so Android tinting works). Original
copyright and licence terms remain with the respective authors.
